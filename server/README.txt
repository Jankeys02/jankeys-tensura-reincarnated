Jankeys' Tensura Reincarnated - server pack (@VERSION@)
Minecraft 1.21.1, NeoForge 21.1.249, Java 21.

1. Install the NeoForge 21.1.249 server (installer: https://neoforged.net, choose "Install server" in this folder).
2. Run install-mods.bat (Windows) or "sh install-mods.sh" (Linux). It downloads the server's mods.
3. Six mods can't be downloaded automatically (their authors block it). The installer prints a link for each.
   Download each file from that link and put it in the "mods" folder, then run the installer again:
   Custom Chest Menus, Easy NPC, FiltPick, Tensura: Better Subordinates, Tensura: Enigmatic, Tensura: Unique Monsters.
4. Accept the Minecraft EULA yourself: edit eula.txt after the first start and set eula=true.
5. Start the server with the run.bat / run.sh that the NeoForge installer made.

Updating: download the new server pack, copy its config, defaultconfigs and kubejs over yours, run the installer again.
Config, quests and scripts are in this zip; mods come from the installer so they always match the release.
